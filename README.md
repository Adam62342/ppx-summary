# Perplexity Summarize (Sine mod)

Click the toolbar button (or press Alt+Shift+P) to open a floating Perplexity panel
at the top right of the page area. It sends the current page's URL with the prompt
"Summarize this page into concise bullet points:".

- Click again on the same page, press Esc, or hit ✕ to close.
- Click on a different page while open to re-summarize that page.
- ↻ re-runs, ↗ moves the conversation into a normal tab.
- Width, height and prompt are configurable in the mod's settings.

Requires Sine (with fx-autoconfig). JS mods need Sine's unsafe/unpublished JS setting enabled.
